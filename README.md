# Intro to Machine Learning

A hands-on introduction to machine learning following the [Kaggle Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning) course curriculum.

## Course Outline

| Notebook | Topic |
|----------|-------|
| [1 – How Models Work](1_how_models_work.ipynb) | Introduction to decision trees and how ML models learn |
| [2 – Basic Data Exploration](2_basic_data_exploration.ipynb) | Exploring data with pandas |
| [3 – Your First ML Model](3_first_ml_model.ipynb) | Building and fitting a Decision Tree with scikit-learn |
| [4 – Model Validation](4_model_validation.ipynb) | Train/validation splits and Mean Absolute Error (MAE) |
| [5 – Underfitting & Overfitting](5_underfitting_and_overfitting.ipynb) | Finding the optimal model complexity |
| [6 – Random Forests](6_random_forests.ipynb) | Ensemble methods and the Random Forest model |
| [7 – ML Competitions](7_ml_competitions.ipynb) | Generating predictions and submitting to Kaggle |

## Requirements

```
pandas
scikit-learn
numpy
jupyter
```

Install with:

```bash
pip install pandas scikit-learn numpy jupyter
```

## Getting Started

```bash
git clone https://github.com/Rahman1096/Intro-to-Machine-Learning.git
cd Intro-to-Machine-Learning
jupyter notebook
```

Then open the notebooks in order, starting with `1_how_models_work.ipynb`.
